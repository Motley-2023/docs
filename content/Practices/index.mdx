## Hub Practices

The Hub follows a set of shared practices that support inclusive participation, continuous learning, and practical innovation.

## Core Practices

- Community-led learning and facilitation  
- Documentation-first knowledge sharing  
- Open collaboration and peer support  
- Learning-by-doing through real projects  

These practices ensure that innovation remains accessible, grounded, and responsive to local needs.
